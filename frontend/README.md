# PayShield Frontend

This is the Next.js 15+ frontend foundation for the PayShield B2B payments platform. It provides a robust, protected shell utilizing React Query, Tailwind CSS, and strict TypeScript patterns.

## ⚠️ Important Note
This scaffold represents the foundational layer only. **US-15 (Auth Shell)** will implement the live API connections, login forms, and finalized routing rules.

## Tech Stack
- Next.js 15 (App Router)
- React 19
- Tailwind CSS v3
- TanStack Query v5 (React Query)
- Axios & Zod
- Lucide React (Icons)
